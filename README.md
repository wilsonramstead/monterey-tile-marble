Single-page demo website for **Monterey Tile & Marble**, a tile, marble and natural-stone
showroom at 1314 Fremont Blvd, Seaside, CA 93955. Built as a sales demo by Wilson Innovations.

- **Live:** https://wilsoninnovations.net/monterey-tile-marble/
- **Business:** 4.5★ × 17 Google reviews · Monterey Peninsula
- **Primary CTA:** call (831) 899-3222 (`tel:+18318993222`) — no contact forms
- **Fonts:** Bona Nova (display) + Ysabeau (body), via Google Fonts
- **Palette:** carrara white + verde marble-green + charcoal, with an oxidized-bronze accent

## Notes
- Static, self-contained `index.html` — inline CSS/JS, works from `file://` and with JS disabled.
- `noindex` while it's a demo (see comment in `<head>`). Remove before going live.
- Gallery uses Unsplash stock as **representative placeholders** — swap in real showroom /
  project photos after the sale.
- Only verified facts from the Google listing are used: name, address, phone, hours, rating,
  review count. No invented email, license numbers, founding year, or "licensed/insured" claims.
